# Elmiron Field Force

A field-force app for pharmaceutical medical representatives in India: an Android app for reps, a web
console for managers and admins, a Supabase database that holds every rule, and an AI gateway.

**New here? Read [`docs/START-HERE.md`](docs/START-HERE.md) first.** It gets the project running from
nothing, explains how it is put together, lists the rules it works by, says which documents to trust,
and says where the work is.

When something the project is waiting for arrives — model access, a second admin, content, a handset, a
decision — follow [`docs/HANDOVER.md`](docs/HANDOVER.md).
